# I. 指令集体系结构

机器指令(简称指令)是指示计算机执行某种操作的命令，一台计算机的所有指令的集合构成了该机器的指令系统，也称为**指令集**。
指令系统是**指令集体系结构**ISA中最核心的部分。ISA 完整定义了软件和硬件之间的接口，是机器语言或汇编语言程序要必须要掌握的技术，尽管现在的某些主板支持直接用 C语言直接进行编程。
ISA 规定的内容主要包括：
1. 指令格式、寻址方式、操作类型以及各操作所需要的操作数个数、类型和寻址约束
2. 操作数的数据类型，以及是按照大端还是小端的方式存放
3. 程序可访问的寄存器编号、数量和位数，存储空间的大小及编址方式
4. 程序员可见的控制状态，eg: 程序计数器PC, 条件码的定义与行为等
ISA 规定了***机器级程序的格式***，因此机器语言或汇编语言程序员是必须要熟悉所用机器的 ISA 指令集体系结构的。
尽管现在 AI时代下的各种高级语言层出不穷，例如深刻影响对 AI 和数据科学的 Python(解释型语言，也是脚本语言)，对标 C/C++性能且安全性高的 Rust 语言，甚至是网站建设和服务器处理的 Java（在 Springboot 的框架下和 JVM 的加持下拥有超强的并发能力，就是太吃内存了）,尽管它未来 10 年内可能会被 Go 语言逐步取代。他们对于开发“非系统应用”或程序员不需要深入结合硬件的“系统应用”来说可能显著提高开发效率，并且不易出错，甚至利用 AI agent 或 harness 开发出质量和可维护性非常高的软件。但由于这些语言的抽象层比较高，隐藏了大量的机器细节。例如 python 和 Java 实际上都运行在虚拟层中，尤其是 Java 是通过 JVM 实现的跨平台。这时候如果需要你对 JVM 进行性能调优，或者需要用 C/C++/Rust 为内存不足 1G 的嵌入式主板 ROM 烧写程序时，你必须利用与硬件结构相关的优化手段来提高性能，这时候如果你明白汇编语言和ISA 及它的底层特性的话，就可以贴合硬件和项目需求开发性能更高的程序，抛开数据结构和算法层面来说。
## 1. 指令的基本格式

*一条指令 == 机器语言的一个语句，他们是由一组有意义的二进制代码组成的*
其基本格式如下：

| 操作码字段 | 地址码字段 |
| ----- | ----- |
+ 操作码：指明指令应执行的操作和功能，是识别指令、理解其作用和确定后面地址码含义的关键，例如算术的加减乘法、程序转移和转移目标地址或子入口地址等都要用它
+ 指令字长：简单来说就是一条指令的总长度。展开详细说就是：一条指令所包含的二进制位数，取决于地址码、操作码长度和地址码的个数。
在一个指令系统中，如果所有的指令字长都是一样的，则称为**定长指令字结构**，优点是：定长的指令取指和译码简单，有助于流水线的实现。如果指令字长随功能而异，则称为**变长指令字结构**，由于主存通常按字节编址，指令字长通常为字节的整数倍。
### a. 零地址指令

零地址：

| OP  |     |
| --- | --- |
指令含义：仅包含操作码，无显式地址。
此指令常见的两种情况：
1. 无须操作数的指令，如空操作、停机、关中断等
2. 用于堆栈计算机的运算指令，其操作数隐含从栈顶和次栈顶（栈顶元素的下一个元素）弹出⏏️，运算结构压回栈顶。（简单来说，就是操作数固定地隐含在某一个特定的位置）
这个很类似于**后缀表达式**。
### b. 一地址指令
一地址：

| --- | ------------- |
具体操作由操作码决定：关于这个有以下两种常见的操作：

	3. 含义：从 A1取出相应的数据，并对它采用 OP 乘法操作 过程：取值->读 A1->写 A1

### c. 二地址指令
二地址：

| OP  | A<sub>1</sub><br> | A<sub>2</sub><br> |
| --- | ----------------- | ----------------- |
指令含义：(A<sub>1</sub> )OP(A<sub>2</sub> )->A<sub>1</sub> 
+ 常用于两个操作数的算术运算、逻辑运算等相关指令
+ 操作数：A<sub>1</sub> 为目的操作数地址(兼结果地址)，A<sub>2</sub>为源操作数地址。如果地址码均为主存地址，完成一条二地址指令需要进行**4 次访存**。（就是取值1次、取两个操作数 2 次、存结果 1 次）
### d. 三地址指令

| OP  | A<sub>1</sub> | A<sub>2</sub> | A<sub>3</sub> 结果Result |
| --- | ------------- | ------------- | ---------------------- |
指令含义：(A<sub>1</sub> )OP(A<sub>2</sub> )->A<sub>3</sub>
+ 常用于需要两个操作数的算术运算，逻辑运算相关指令
+ 在三地址指令中，A<sub>1</sub> 和A<sub>2</sub> 为两个源操作数地址，A<sub>3</sub>为结果地址。如果地址码均为主存地址，完成一条三地址指令需要 4 次访存(也就是取值 1 次，取两个操作数 2 次，存结果 1 次) 
### 剩余的指令

实际上还有一条四地址指令，只不过这个用的不多，这个简单一提
四地址指令的指令含义为：(A<sub>1</sub> )OP(A<sub>2</sub> )->A<sub>3</sub>  A<sub>4</sub>则为下一条将要执行的指令的地址。 
## 2.定长操作码指令格式

定长操作码指令在指令字的最高位部分分配**固定位数**表示操作码。一个n位操作码字段的指令系统最多可表示2<sup>n</sup> 条指令。
#### 定长指令操作码的优点：
+ 定场操作码有利于简化硬件设计并提高译码速度
+ 控制器的电路设计简单
#### 定长指令操作码的缺点：
+ 电路设计相对固定，灵活性比较低

### 1）扩展操作码的指令格式
为了摆脱定长操作码指令格式“灵活性差”，指令种类单一的缺点。计算机中常采用可变长度操作码，这种操作码可以在有限的指令字长内支持丰富的指令种类。
但是可变长度操作码也使指令的操作码字段位数不固定，且分散在指令的不同位置。这增加了指令译码和分析的难度，使控制器设计更加复杂。最常见的变长操作码方法为扩展操作码。
扩展操作码使**操作码长度随地址码减少而增加，不同地址数的指令有不同长度的操作码，从而有效缩短了指令字长。**

### ⚠️ 设计扩展操作码指令格式时必须注意的要点
+ **不允许短操作码成为长操作码的前缀**，即短操作码不能和长操作码的前面部分相同(这一点和哈夫曼编码中的前缀码很像)

## II. 指令的类型

### a. 数据传送指令
*主管主存和 CPU 之间进行数据传输*

| 传送指令的含义 | 传送指令的名称                              |
| ------- | ------------------------------------ |
| MOV     | 寄存器之间的传送                             |
| LOAD    | 从内存单元读取数据到 CPU 寄存器，也就是把存储器中的数据放到寄存器中 |
| STORE   | 从 CPU 寄存器写数据到内存单元                    |
| PUSH    | 进栈操作                                 |
| POP     | 出栈操作                                 |
### b.算术和逻辑运算指令

| 指令含义 | 指令作用及名称       |
| ---- | ------------- |
| ADD  | 加法指令          |
| SUB  | 减法指令          |
| MUL  | 乘法指令 multiply |
| DIV  | 除法指令 division |
| INC  | 加 1，自增 1      |
| DEC  | 减 1，自减 1      |
| AND  | 与             |
| OR   | 或             |
| NOT  | 取反            |
| XOR  | 异或            |

### c.移位操作指令

移位指令主要有**算术移位、逻辑移位、循环移位**等。
### d.顺序控制指令

顺序控制指令也是一种程序控制类指令，用来改变程序执行的顺序

| 指令含义   | 指令类型                       | 指令用途                                     |
| ------ | -------------------------- | ---------------------------------------- |
| JMP    | 无条件跳转                      | 在任何情况下都可以执行转移操作                          |
| BRANCH | 条件跳转                       | 仅在特定条件满足下执行转移操作，转移条件通常来自某个标志位的值或多个标志位的组合 |
| CALL   | 调用                         |                                          |
| RET    | 返回🔙                       |                                          |
| TRAP   | 陷阱🪤，在操作系统 OS 中也叫做**陷入指令** |                                          |
需要注意的是：调用指令和转移指令的区别在于：调用指令或保存下一条指令的地址(返回地址)，以便子程序执行结束时可以返回到**主程序继续运行**。***转移指令不返回。***
### e.输入输出指令
*主管 I/O 设备和 CPU 之间进行数据传输*
输入输出指令用于完成 CPU 与外部设备交换数据或传送控制命令及状态信息ℹ️
### f.CPU控制指令
CPU 控制命令主要有**停机、开中断、关中断、系统模式切换（从 OS 的内核态切换到用户态的原语），以及进入特殊处理程序等**。这类操作只能在操作系统 OS 内核代码中使用，用户不能使用这些代码，以免对操作系统及其硬件造成危害。
