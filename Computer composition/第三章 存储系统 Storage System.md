# I. 存储器的分类

## 1. 按存储元件分类

存储元件必须有两个截然不同的物理状态，才能被用来表示二进制代码 0 和 1。常用的存储元件介质主要有：半导体器件、磁性🧲材料（早起的磁带）和光介质（DVD & CD）。这三种也可以称为半导体存储器（例如 DRAM、SRAM）、磁表面存储器（分为磁盘存储器和磁带存储器）和光介质存储器（光盘存储器）

## 2. 存取方式分类

- 随机存储存储器（RAM, random access memory）

按地址访问存储单元，可对任意存储单元进行读和写，且存取时间与物理位置无关。并且因为每个地址译码时间相同，所以，在不考虑芯片内部缓冲的前提下，每个单元的访问时间是一个常数，与地址无关。（简单来说就是：读写灵活、内存读取比较方便）

半导体存储器（DRAM、SRAM）属于随机存取存储器，可用作 Cache 和主存储器。

- 顺序存取存储器（SAM, sequential access memory）

信息按照顺序存放和读出，存取时间取决于数据在介质中的位置，通常以记录块为单位编制。典型代表是磁带，具有容量大但速度慢的特点（冷知识🥶：现在一些大型数据存储中心或者档案馆还在用磁带记录和保存数据，数据迁移的时候直接用卡车🚛统一运走！）

- 直接存取存储器（DAM, direct access memory）

兼具随机访问和顺序访问的特点，可以先直接定位到目标区域，再根据目标区域，按照顺序逐层（逐道）读取数据（顺序读取数据）。

这个就可我们平常认识的存储介质很相近了，例如机械硬盘，固态硬盘都属于直接存取存储器。

- 相联存储器（AM, associative memory）

当然有些情况下可能不清楚所访问信息的地址，只清楚访问信息的内容特征，此时只能按内容检索到存储位置进行读写，这种存储器称作按照内容访问存储器(content addressed memory, CAM)和相联存储器

简单来说就是按内容而非地址进行存取，查找速度快且与存储位置无关。当他们的成本高💰、容量小。主要用于 TLB 快表、路由表等容量小但高速的场景。

## 3. 按信息ℹ️的可更改性分类

按信息的可修改性可分为可读可写存储器(RAM random access memory)和只读存储器(ROM read only memory)。ROM 中的数据一旦确定一般不能修改（尽管现在已经出现了类似 E2PROM、Flash等可擦除 ROM），但在某些情况下可以重新写入。 RAM 和 ROM 都采用了随机存取方式进行信息的访问。 

## 4. 按断电后信息的可保存性分类

- 易失性存储器（又称作挥发性存储器）

断电后，信息即消失🫠，如 RAM，Cache 等（可以想想内存）

- 非易失性存储器（又称作不 挥发性存储器）

断电后数据仍然可以保持，ROM、磁表面存储器（磁盘）、光存储器（光盘💿）等非易失存储器信息可以一直保留。

此外，若读操作会破坏存储单元的原有信息，则成为破坏性读出，读出后需立即执行再生操作以恢复数据；若读取不改变原有信息，无需再生，则称为非破坏性读出

# II. 主存储器的组成与基本操作

 在主存储器中，由一个个存储 0 或 1 的记忆单元（cell）构成的存储阵列是存储器的核心部分。这种记忆单元也被称作存储元、位元。其中由记忆单元构成的存储矩阵（也称为存储体、存储阵列）是存储器的核心部件。每个记忆单元是一种具有两种稳定物理状态可以表示 0 和 1 的器件。

为了存取存储体中的信息，必须对存储单元进行编号（编址）。所编号码就是地址。编址单位是具有相同地址的的一组记忆单元，称为一个存储单元。另外编址单位可以是一个字节或一个字。

现代计算机普遍采用字节编址的方式，即每个地址对应1 字节（8 位）数据。存储体内一个地址中有一字节。

对存储单元进行编号的方式称为编址方式，可以按照字节编址也可以用按字编址。

指令执行过程中访问主存时，首先将目标地址送入主存地址寄存器 MAR 中，然后再通过地址线将主存地址送到主存的地址寄存器中，以便地址译码器进行译码，并选中相应单元。同时CPU 将读写信号通过控制线送到主存的读写控制电路。

如果是写操作，CPU 同时要将要写的信息送到主存数据寄存器 MDR 中。在读写控制电路的控制下，经数据线将信息写入选中☑️的单元。

如果是读操作，就将主存读出选中的单元送到数据线。然后被送到 MDR 中。

数据线的宽度与 MDR 的宽度相同，地址线的宽度与 MAR 的宽度相同。下图中采用的是 64 位的数据线。在字节编址的方式下，每次最多可以存放 8 个单元的内容。地址线的位数决定了主存地址空间的最大寻址范围。36 位地址的最大寻址范围位 0-2^36-1，地址从 0 开始编址。

# III. 存储器的层次化结构

在数据的提取和访问中，使用单一的存储介质来达到相同的传输与交换速度无疑是最好的。但是那样做的话成本非常高昂，并且也无法提供更高的硬件兼容性。所以采用不同介质和材质的存储器依然是现代计算机存储的最佳选择。

因为不同存储部件的成本和造价不同，各个存储器之间的访问与传输速度也存在差距。为了弥补不同硬件间访问的差距，缓解存储系统在容量、速度与成本之间的矛盾，更好的发挥存储器的优势和性能。现代计算机普遍采用多级存储结构。从上到下，各级存储器的单位价格逐渐降低，存取速度越慢的存储器，容量越大，同时 CPU 访问对其访问的频率也在相应的降低。

![image.png](%E7%AC%AC%E4%B8%89%E7%AB%A0%20%E5%AD%98%E5%82%A8%E7%B3%BB%E7%BB%9F/image%201.png)

该层次结构主要体现为两个关键层级：Cache-主存层和 主存-辅存层

Cache（集成在 CPU 内的高速缓存）和主存可以直接与 CPU 交换信息；辅存则需要通过主存间接与 CPU 进行通信。

主存（RAM & ROM）作为枢纽，能与 CPU、Cache 及辅存双向交换数据。

存储层次的核心思想如下：

上一层存储器作为下一层的高速缓存。当 CPU 访问数据时，按照 Cache → 主存 → 辅存的顺序进行逐级查找。如果所需数据不在上层，则从下层逐级调入；先从硬盘（辅存）读入内存（主存），再加载到 Cache。

从 CPU 的视角看：Cache-主存层的速度接近 Cache，而容量和单位接近主存。主存-辅存层的速度接近主存，而容量和单位成本接近辅存。

两层机制的实现主要目标和实现方式不同：

 Cache-主存层主要为了缓解 CPU 与主存速度不匹配的问题，数据调度***由硬件自动完成.*** 对程序员透明。

主存-辅存层主要解决存储容量不足的问题，数据调度由硬件和操作系统 OS 协同完成，对应用程序员透明。

随着主存-辅存层的不断发展，逐渐形成了虚拟存储系统（详见操作系统 OS 篇中的虚拟内存技术）。在该系统中，程序员使用的地址空间（虚拟地址空间）远大于实际主存容量，程序可按照更大的逻辑地址空间进行编写。

*在 Cache-主存层和主存-辅存层中，上一层的内容始终是下一层内容的子集副本，即 Cache 中的数据来自主存，主存中的数据来自辅存。*

# IV. 存储器的性能指标

### A. 存取时间

存储器完成一次读/写操作所需要的时间。其中读出时间是指从主存接收到有效地址到数据有效输出的时间，写入时间是指从主存接收到有效地址到数据成功写入指定单元的时间。

### B. 存取周期

存储器进行连续两次独立的读写操作所需的最小时间间隔。这里也称为读写周期/访存周期。他是指存储器进行一次完整的读写操作所需的全部时间。

存取时间不等于存取周期。通常存取周期大于存取时间，因为每次读写操作后，存储器需要一定时间恢复内部状态，对于破坏性读出存储器 DRAM 来说，读出后必须立即再生数据，因此他的存取周期往往大于存取时间的，甚至可以用Tm = 2Tn( Tm 为存储周期，Tn为存取时间)

### C. 存储器带宽

存储器每秒可以传输的最大数据量。它也可以称作主存带宽或数据传输率，表示每秒从主存进出信息时的最大数量，单位为字/秒/字节/秒 B/S 或位/秒（b/s）

例如若存储周期为 50ns，每个周期可传输 64 位数据，则理论带宽为 64b/50ns = 1.28Gb/s .在实际系统中，存储器常被组织成多模块结构，允许多个模块并行工作，从而将总带宽提升至单模块带宽的若干倍。

## 公式

存储速度=数据传输率 = 数据的宽度/存储周期 （数据的宽度即数据字长）

单位成本 ：每位价格 = 总成本 / 总容量

存储容量：存储字数 * 字长 （位数反映存储字长）
