# I. 半导体随机存储器

随机存储器RAM 分为 静态 RAM (SRAM Static RAM)和 动态 RAM（Dynamic RAM），二者均为易失性存储器。
在现代计算机中，主存主要采用 DRAM，也就是我们常说的内存条一般采用的是 DRAM。而在 CPU 里的 Cache 高速缓存使用的是 SRAM。

> 实际上，关于 SRAM 和 DRAM 的分类还有另一种说法。按照内存制造工艺的不同，可以将半导体 RAM 分为双极型 RAM 和 MOS 型 RAM 两大类，MOS 型的 RAM 又区分为静态 RAM，即 SRAM。和动态 RAM，即 DRAM。
## 1. SRAM 的工作原理

地址相同的多个存储元件构成一个存储单元。若干存储单元的集合构成存储体。
SRAM 的存储元基于双稳态触发器，即六晶体管MOS。利用电路的两个稳定状态分别表示二进制的 0 和 1。
SRAM 的静态特征体现在：***读操作为破坏性读出，因此无需信号📶再生***
SRAM 的优点：存储速度快
SRAM 的缺点：功耗较大、成本高💰，通常用于高速缓冲存储器

## 2. DRAM的工作原理

DRAM 利用栅极电容上的电荷来存储信息。其规则是：有电荷表示 1，无电荷表示 0
其基本存储元只有一个晶体管和一个电容构成。结构比较简单，其集成度要远高于 SRAM

![[Pasted image 20260823014615.png|553]]

***DRAM 的内部结构扫描***

DRAM 的特征：价格相对于 SRAM 比较便宜、功效小，容量大。
DRAM 的缺陷：存取速度比较慢、电荷会因漏电而逐渐丢失。必须通过定时的刷新以维持数据。并且DRAM 的读出为**破坏性读出** ，数据需要在读取后立即再生。

因此综上所述，DRAM 大范围被用于大容量主存系统。例如主板上的内存条。其在成本、容量和性能之间有很好的平衡。

## 4. 存储芯片的组成

一颗存储芯片由存储体、I/O读写电路、地址译码器和控制电路等部分组成。
1)  存储体（存储矩阵）
存储体是存储单元的集合。通过行选择线🧵(X)和列选择线(Y)共同选中☑️目标单元。位于相同行列交叉点上的多个位（位平面数）被同时读/写。
2) 地址译码器
地址译码器是用来将输入地址转换为⇄译码输出线上的高电平信号，并用高电平信号📶来驱动相应的读/写控制电路。其中关于地址译码方式分为以下两种：
   i. 单译码法（一维译码）：
   仅使用一个行译码器，同一行中的所有存储单元的字相连接，构成一个字。构成部分可以被同时读写。**缺点：译码器输出线数量过多。**
   ii. 双译码法（二维译码）：如下图所示，地址译码器分为X(行)和 Y(列) 两个部分。通过行与列的交叉点唯一确定一个存储单元。这种方式一般是当前 DRAM 芯片普遍采用的译码结构。
3)  I/O 电路
用于控制被选中存储单元的读/写，具有信号放大的作用。

![[Pasted image 20260823013610.png]]

3) 片选控制线：因为单个存储单元芯片的容量有限，一般无法满足计算机对主存存储容量的要求，因此需要将多个芯片扩展为一个阵列，如下图的 DRAM 级联阵列一样。因此在访问某个字的时候，必须“选中”该存储字所在的芯片，而不会选中其他芯片。因此需要（经片选控制线传输）有片选控制信号线 ，这里的片选线一般用$\overline{CS}$ 表示，意为`chip select`。
4) 读写控制线：根据 CPU 发出的读写指令，通过读写控制线选中相应的单元来执行相关的读写操作。这里的读写控制线一般用$\overline{WE}$ 表示，意为 `write enable` 写使能。

## 5. DRAM芯片的关键技术

### a. 地址引脚复用技术

因为 DRAM 经常被用于主存，也就是我们常说的内存条。它的芯片容量相对于基于 SRAM 的 Cache 来说要大的多。而且 DRAM 一般是由级联 DRAM 阵列组成，所需要的地址位数也变较多。为了降低芯片地址引脚的数量，通常采用***地址引脚复用技术***
#### 地址引脚复用技术

利用地址引脚复用技术，行地址和列地址通过相同的引脚分两次完成先后的输入操作，从而使地址引脚的数量减少一半。

具体原理详解：
先看 DRAM 的引脚图：
(a) 图中所示的 DRAM 共有 11 根地址引脚线A<sub>0</sub>~A<sub>10</sub>, 在行选通信号$\overline{RAS}$ 和列选通信号 $\overline{CAS}$ 的控制信号下分时传输行、列地址。有四根地址引脚线D<sub>1</sub> ~D<sub>4</sub> , 因此每个芯片同时读出 4 位数据。用$\overline{WE}$读写控制引脚，在低电平时为写操作。$\overline{OE}$ 为输出使能驱动引脚。低电平有效，高电平时断开输出。
(b) 图中 DRAM 采用了三维结构，芯片存储容量为2048 × 2048 × 4位。行列地址共 11 位，有 4 个位平面，在每个行、列交叉处的 4 个位平面的数据都需要同时进行读写。
DRAM 芯片需要刷新。刷新时只给各芯片送行地址和$\overline{RAS}$信号，芯片中某一行的所有位元被选中并进行读操作，每次读后再生，即某位元读出是0则充分放电，读出是1则进行充电。对于由图(b)中芯片组成的存储器，其存储矩阵为2048×2048×4，因此只要2048次刷新操作就可将整个存储器刷新一遍。***由于刷新按行进行，所以无须进行列寻址***。芯片内部有一个行地址生成器（也称刷新计数器），由它自动生成刷新行地址，因而刷新计数器的位数与行地址位数相同。行地址缓冲器和刷新计数器通过一个多路选择器（MUX）将选择的行地址输出到行译码器。
刷新周期定义为，上次对整个存储器刷新结束的时刻，作为开始点到下次对整个存储器全部刷新一遍为止的时间间隔，也就是对某一个特定的行进行相邻两次刷新的时间间隔。

> 简单说，刷新周期定义为对某一特定行完成一次刷新后，到下一次对该行再次刷新的时间间隔。

目前公认的刷新周期标准是64ms，但有些器件也不一定是 64ms。

### b. 刷新机制和阵列设计的优化
#### DRAM 刷新数据的原理：
DRAM 芯片需要定期刷新数据以维持所存信息，刷新时，仅向芯片提供行地址和$\overline{RAS}$ 信号📶，即可选中某一行的所有存储单元执行读写操作。
因为 DRAM 采用的是***破坏性读出***的方式，每次读取后必须立即再生。*若读出为0，则将电容充分放电；若读出为 1，则重新充电。*
#### DRAM 芯片行、列优化设计原则

假设一个 DRAM 芯片的存储容量为 2<sup>n</sup> × b位，其存储阵列的行数为 r(row)，列数为c(column)，则满足2<sup>n </sup> =r × c。整个阵列的地址位数为n, 其中行地址占log<sub>2</sub> r位，其中列地址占log<sub>2</sub> c位，因此有 n = log<sub>2</sub> r +log<sub>2</sub> c。
回到 DRAM 中，因为 DRAM 采用的是地址引脚复用技术，引脚数量由行、列地址位数中的较大者决定，为了最小化地址引脚数，应该让r和c尽可能的接近。
另外，DRAM 按行刷新，行数越少，刷新的开销就越低，因此还需要满足条件 r <= c。
因此综合上面两方面考虑，通常将 DRAM 的阵列设计成***行数略小于或等于列数的近似于正方形的结构***。

### c. 缓存机制与突发传输
### d. DRAM芯片行缓冲器的容量的计算

芯片内部设有一个行缓冲器，用于缓存被选中☑️行中所有的列的数据。行缓冲器的容量等于一行中所有存储单元的数据总量——即 **列数 × 每个存储单元的位数 （4 列 × 8 位 = 32 位）。**
当某一行被选中后，该行中的全部数据被一次性加载到行缓冲器中，后续可在每个时钟周期内连续输出一个存储单元的数据(8位)。从而支持突发传输，即在寻址阶段提供首地址，随后连续读取多个相邻存储单元的数据，从而显著提升了有效存储带宽。

> 注意⚠️：行缓冲器一般是由 SRAM 实现的。

## 6. 同步DRAM

因为普通的 DRAM 的数据存储效率和时效较低，目前更广泛使用的是同步 DRAM，也就是 SDRAM。这种芯片与传统的 DRAM 不同， SDRAM 的数据读写与系统时钟同步，能够以“CPU-主存总线”的形式高效率的运行。在连续访问同一行（页面）内的数据的时候，可以实现***突发传输***，并显著降低甚至可以避免插入等待状态。
在异步 DRAM 中，CPU 发出地址和控制信号后，必须要等待一段时间后，时间延迟可长可短不确定，才能获取数据并完成写入操作。这期间，CPU 将不停的轮询访问存储器的状态信号，无法完成其他任务（类似于死锁状态），从而降低整体的运行效率。
而 SDRAM 在系统时钟的驱动下工作，它将 CPU 发出的地址信号和控制信号保存（锁存），并在预设的若干个时钟🕰周期后返回数据，或是完成写入数据的操作；使CPU 无需等待，可在延迟期间执行其他命令，显著提升系统性能。

> [!info]
> 尽管如此，SDRAM 同步 DRAM 还是需要定期刷新的
> 

# II. 非易失性存储器

## 1. ROM （Read-only memory）只读存储器

尽管 RAM 和 ROM 都支持随机访问，但与前者不同的是，ROM 属于非易失性存储器
ROM 存储器的显著优点：
+ 结构简单，位密度高于 SRAM 等可读写存储器
+ 断电后数据不丢失，可靠性高
根据制造工艺的不同，ROM 也可以分为多种形式：

| ROM 种类            | 特点                                                                                |
| ----------------- | --------------------------------------------------------------------------------- |
| 掩膜式 ROM (MROM)    | 软件固件由 OME 第三方厂商写死进芯片，用户不可更改                                                       |
| 一次可编程 ROM(PROM)   | 允许用户进行一次性编程                                                                       |
| 可擦除可编程 ROM(EPROM) | 尽管它支持多次编程，但每次擦除需要通过紫外线照射的方式，照射整块芯片。并且它的擦除次数有限、写入速度慢、难以满足主存对高速随机读写的需求，因此它并没有替代 RAM |

## 2. Flash存储器 （闪存存储器）

> [!quote]
> 除了主存和 Cache 需要保存容易易失性数据外，我们平常使用计算机肯定需要将更多的数据保存到非易失性的存储器中。例如 OS 启动所需要的 BIOS (basic input/output System)。在早期的计算机主板上 BIOS 是直接写死在 MROM(Mask read-only memory)掩模是存储器或 EPROM 中的，后续无法维护和更新。现代计算机的主板普遍采用 Flash 存储器存储 BIOS，用户可以直接通过 OS 更新或单纯的固件软件更新的方式将旧有的BIOS 系统擦除并更新。
> 

> 闪存储储器用的非常广泛，日常使用的 U 盘和 SD 卡 实际上就用到了闪存芯片技术

Flash 存储器又称为闪存，是一种在 EPROM 基础上发展而来的非易失性存储器，同时具有 ROM（只读存储器）和 RAM（随机存储器）的部分优点：
1. 断电后可长期保存数据
2. 支持电擦除与在线重写
3. 无需使用紫外线照射等特殊设备进行擦除重写
4. 读取速度接近 RAM
但是它也有缺陷，例如：写入速度较慢，尤其是随机写入速度较慢，读写性能不对称。

> [!warning]
>  要特别注意，U 盘的 Flash 闪存也是基于ROM 只读存储器的，也是 ROM 的一种
> 

## 3. 固态硬盘（SSD solid state disk  NVMe 颗粒）
固态硬盘是基于 Flash 闪存存储器构建的存储设备。由控制单元和存储单元 Flash 存储器芯片阵列组成。SSD 继承了闪存存储器的重要特性：非易失性、无机械部件、读取速度快。
相比传统的机械硬盘。SSD 具有读写速度快、功耗低、抗震性能强等优势。但也存在价格较高、且数据写入寿命受限于 Flash 存储器的擦除次数，寿命相对于机械硬盘来说较短。（当然用于 NAS 和企业级固态硬盘的寿命和性能还是很好的）

> [!NOTE]
> 因为固态硬盘在写入数据的需要需要判断哪些块可以写，哪些块需要将数据进行迁移或删除。所以固态硬盘的随机速写操作会比单纯的读写操作要慢一些。当然现在采用动态磨损均衡技术的 SSD 更是如此。

# III.多模块存储器

*多模块存储器也可以被称为“双端口RAM ”和多模块存储器*

多模块存储器是一种空间并行技术，通过多个结构完全相同的存储模块并行工作来提高存储器的吞吐率。因为 CPU 的速度远高于存储器，要想充分利用 CPU 资源，必须要在一个存储周期内连续获取多条指令和多条数据。多体交叉存储器就是基于这一思想设计的。
根据模块间地址分配方式的不同，分为连续编址和交叉编址两种方式。
## 1. 连续编址方式 （用的不多，了解即可）

特征：高位地址位模块号（或体号），低位地址为模块内地址（或体内地址）。
编址方式：低位的体内地址总是被送到由高位体号确定的模块内进行译码操作。
访问一个连续的主存块时，总是先在一个模块内进行访问，**直到该模块访问完毕后才转到下一个模块访问**
由于 CPU 按顺序访问存储模块，各模块之间不能并行访问，因此该存储器的吞吐率较低。

> [!NOTE]
> 因为模块内的地址是连续的，但存取方式还是按照串行存取的。因此这种存储器在本质上依然是顺序存储器

## 2. 交叉编址方式 （常用，重点看）

*假设有 m个模块，每个模块含有 K 个存储单元，则模块编号由地址对吗取模决定，即***模块号 = 单元地址 %m*** 


*图为交叉编址的多体并行存储器*

特征：低↓位地址位模块号（或体号），高↑位地址为模块内地址（或体内地址）。(正好与连续编址相反)
编址方式：由于连续的数据被依次分布（存放）在不同的模块中，程序和数据块在物理上是交叉存放的。采用此方式的多模块存储器称为交叉存储器。通过多个结构完全相同的存储模块**并行**工作，这种设计可以在访问连续地址时显著提升存储器的吞吐率

交叉存储器有两种启动方式
#### 轮流启动方式
若每个模块一次读写操作的位数正好等于数据总线的位数，模块的存取周期为 T，总线周期为 r，则为实现轮流启动方式，存储器交叉模块数应当满足： $m = T/r$
#### 交叉存储器存取时间和带宽的计算

按每隔1/m个存取周期轮流启动各模块，则每隔 1/m个存取周期就可以读写一个数据，存取速度将提高 m倍。
一个 4 体低位交叉轮流启动的存取时间方法中，一个交叉存储器要求其模块大于或等于 m。以确保启动某个模块后经过 mr的时间后再次启动模块时，其上次的存取操作已经完成✅（以保证流水线不间断）。
这种方式下，连续存储m个字段所需时间为：
t<sub>1</sub> = T+(m-1)r
而顺序方式连续存取 m个字所需要的时间为t<sub>2</sub> = mT。两者对比下来 t<sub>1</sub>比它有很大的提高。
#### 这种方式有可能带来的冲突

> [!warning]
> 在理想情况下，m体交叉存储器每隔1/m存取周期可读/写一个数据。若相邻的 m次访问的访存地址出现在同一个模块内，则会发生访存冲突。此时需要延迟发生冲突的访存请求。
> 

#### 同时启动方式
当所有存储模块一次并行读写的总位数恰好等于存储器数据总线宽度时，采用同时启动方式最佳。

例如，使用8个16M×8位的DRAM 芯片构成一个128MB 内存条：每个 DRAM 芯片内部为4096x4096×8位的存储阵列（行地址与列地址各12位），含8个位平面。

CPU发出的主存地址被拆分为行地址和列地址，通过分时复用方式先后送入DRAM 芯片的行，列地址译码器，选中行列交叉处的8位单元进行读/写操作。因此，单个芯片每次传输8位，8个芯片同步工作，可一次性提供64位数据，匹配64位总线宽度。

需要注意的是，并行访问以连续8字节为单位进行，即每次读取的数据只能来自地址对齐的块（如第0～7，8～15， ，8k～8k+7单元）。若访问一个 int 型（4字节）数据时起始地址未对齐（如地址6，占用第6~9单元，横跨两个访问块），则需两次访问；若地址按4字节对齐（4的倍数），则一次即可完成。这正是内存访问要求数据对齐的根本原因。

# IV. 主存储器与 CPU 的连接🔗

## 1. 连接原理

主存储器通过三大总线相连，他们分别是（这三大总线在计组中非常重要，后面指令寄存器那里还会用）
+ 数据总线 Data Bus (DB)
用于在各部件之间双向传输数据信息，包括指令、操作数、状态字、中断类型号等。其位数反映了 CPU 一次能并行传送的数据位数。
+ 地址总线 Address Bus (AB)
用于指定要访问的主存单元或 IO 端口的地址。它是单向总线，其位数决定了系统最大的寻址空间。为了降低芯片制造成本💰（减少不必要的引脚）部分硬件架构采用地址线和数据线复用设计，这种方式下，地址与数据信息分别在同一组物理线路上传输。
+ 控制总线 Control Bus (CS)
用于传输各种协调与控制信号📶，以确保各部件同步、有序的工作。典型的信号包括：时钟🕰、复位、总线请求/允许、中断请求/响应、存储器读写、IO 读写、传输确认等。控制总线由若干条单向或双向信号线组成，具体的构成取决于系统设计要求。

这些总线都是系统总线。
主存储器通过三大总线与 CPU 相连，三者协同完成数据传输、地址定位和操作控制。其中：
+ 数据总线的位数和它的工作频率共同决定了**数据传输速率**，乘积与理论带宽成正比。
+ 地址总线的位数决定了 CPU 可寻址的最大内存空间
+ 控制线因存储器类型而异。
+ SRAM 芯片通常包含“片选线”和“读写控制信号线”
+ ROM 芯片仅需要片选线
+ DRAM 芯片一般不设置独立片选线，DRAM 的芯片选择可通过“行列”地址选通或外部译码逻辑实现。
因为单个存储芯片的容量有限，实际的存储系统中需要通过**存储器扩展技术**将多个芯片集成在内存条上，并和主板上的 ROM 共同构成计算机所需要的主存空间，再经由系统总线与 CPU 的连接🔗。
为此，为了解决单个存储芯片的字数（存储单元数量）或字长（每个存储单元位数）无法满足实际主存的问题，一般采用下面两种方式扩展主存容量——***位扩展法和字扩展法***
## 2. 主存容量的扩展
### a. 位扩展法

1. 作用：用于增加存储字的长度，**适用于 CPU 总线宽度大于单个芯片数据位宽的情况**。
2. 特征：通过并联多个芯片，使其总数据位宽与 CPU 的总线匹配
3. 连接方式🔗：各芯片的地址线、片选线和读写控制线并联，接到主存系统对应的总线上。数据线单独引出，分别连接到系统数据总线的不同位。所有芯片同时工作，共同提供一个完整字。

*下图中使用 8 片 8K×1位的 RAM 芯片构成8K×8位的存储器。（21引脚总数，采用地址复用技术的话位 10）各芯片的地址线A12~A0，片选线和读写控制线均连接🔗在一起，每片的数据线依次对应 CPU 数据总线的一位*


### b. 字扩展法

1. 作用：用于增加存储单元的数量（扩大地址空间），而存储字的位数已满足系统要求。此时，系统数据总线宽度等于芯片数据位宽，而地址总线位数多于芯片地址线位数。

> 简单来说，字扩展法可以增加存储器的存储字数，可以更好地利用 CPU 的寻址能力

2. 连接方式🔗：各芯片的地址线连接至系统地址总线的低位；数据线和读写控制线并联至系统总线；系统地址总线的高位经译码器生成片选信号，分时选中不同的芯片。各芯片分时工作。
##### 另一种方法：线选法
用n条线表示n个片选信号，优点是电路简单；缺点：地址空间不连续
##### 另一种方法：译码片选法
用n条线表示2<sup>n</sup>个片选信号，电路复杂，地址空间可连续
##### 位扩展
可以使存储字长变得更长，从而更好的发挥数据总线的数据传输能力。
