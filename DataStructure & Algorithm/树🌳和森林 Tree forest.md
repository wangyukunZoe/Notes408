# I. 树的定义

## 1. 树🌳的概念

树🌳是 n (n >= 0) 个结点的有限集，当n=0 时，称为空树。

任意一棵非空🈳树必须满足：

1)  有且只有一个特定的元素称为*根结点*
2)  当 n > 1 时，其余结点可以分为 m (m > 0) 个互不相交的有限集 T1, T2, T3 ... Tm,  其中每个集合本身又是一颗树，称为根的子树。（这里就会涉及到后面的树的深度和树节点的层次关系的相关内容）
由此可见，树的定义是***递归*** 的。在定义每个节点中依次、不断的调用自身元素。因此树是一种典型的递归数据结构。这一点在后面进行树的先序遍历、中序遍历和后续遍历时会更明显。
从另一方面，逻辑结构层面上讲，树同时也是一种分层结构，具有两种特征，分别是：
a. 根结点没有前驱。 ***除根结点以外的每个节点有且只有一个前驱*** ，简单来说，就是根结点以外的节点，他们只有一个父节点，不可能存在多个父节点。
b. 所有结点均可拥有 0 个或多个后继元素。也就是说，每个结点均可与它的下一层的 0 个或多个结点建立直接关系。

树非常适用于表示具有层次结构的数据。

树的根结点无上层节点，树的其他节点最多只与上一层的一个结点（它的父节点）存在直接关联。
另外，树有一条很重要的性质——在包含n 个节点的树中，拥有 n-1 条边。

## 2. 树的基本术语

![[Pasted image 20260824012513.png|623]]

*一棵树的树意图*
### 1）祖先、子孙、双亲、兄弟👬和堂兄弟节点

> 关于这里，可以看看DOM树的节点遍历，CSS中的很多样式选择器, 例如：兄弟选择器 .{}等都用到了树的思想。

+ 结点： 树中的一个独立单元。树的***根结点*** 是唯一一个没有前驱的结点。其余结点都包含一个数据源素和若干指向其子树的分支。如上图中的 2,10,6,9 等都是结点。
+ 结点的度：结点拥有的子树称为结点的度
+ 树的度：树的度是树内各结点的最大值
+ 叶子🍃：***度为 0***的结点称为叶子结点或终端结点。简单来说，叶子节点就是后面没有任何分支，不会与后面结点产生联系的结点
+ 非终端结点：度不为0 的结点称为分支节点，或是非终端结点。除去根节点外，非终端结点也被称为内部结点。
+ 双亲和孩子结点：简单说，在一棵树下，一个结点下面如果还有与它相关的附属结点，那些附属结点就属于孩子结点。双亲结点就是结点间他们拥有共同的父节点，即祖先结点
+ 兄弟结点👬：简单说，就是在同一颗树上并且还是同一层上的结点。例如在树中的第二层拥有B、C、D. 他们都属于兄弟结点
+ 祖先结点：从根结点到目标结点的分支上的所有结点。简单说，就是每个元素的父节点。
+ 堂兄弟节点：树的同一层上的所有结点。也称为双亲在同一层的结点互为堂兄弟节点。
### 2）结点的层次、深度和高度

+ 结点的层次：结点的层次就是以树的高度为依据，每个树的结点都在同一个“平面上”。一般情况下，结点的层次从 0 开始算起。根结点是第一层。 根的孩子结点为第二层。
+ 树的深度和高度：树中结点的最大层次称为树的深度和高度。本实例图中的树的高度为：4

注意⚠️：树的高度和深度的计算一点要掌握清楚。因为到了 AVL 树的也会树的高度差会作为——平衡二叉树的依据。

### 3) 结点的度和树的度

树中一个结点的孩子个数称为该结点的度。***树中所有结点的度的最大值为 ***B
### 4）分支节点和叶节点

度大于 0 的结点属于分支结点，也称为非终端结点。

叶子🍃：***度为 0***的结点称为叶子结点或终端结点。简单来说，叶子节点就是后面没有任何分支，不会与后面结点产生联系的结点

### 5）有序树和无序树

如果有一棵树，它树中的结点依次按照从小到大的次序排列（不能互换）。则这种情况下称他为有序树。 
### 6）路径和路径长度

树的路径长度是从树根到每个结点的路径长度的***总和***。路径长度是该路径上边的数目。

### 7）森林
简单来说，森林就是包涵不同种类的树的集合。一个森林可以包涵一个空结点或者是二叉树或满树。


# II. 树的性质 （重要）

> 这部分现在要记，考前看一看，喝前摇一摇

1. 树的结点数 = 树的总度数+1
2. （另外还有一个）树的节点数 n 等于所有结点度数之和。
3. 度为 m的树中。第i 层上至多有 m<sup>i-1</sup> 个结点（i >= 1）
4. 高度为h 的m 叉树至多有 (m<sup>h</sup>-1)/(m-1) 个结点
5. 度为m ,具有n个结点的树的最小高度 h 为 log<sub>m</sub>( n (m-1) + 1) `向上取整`
6. 度为m ,具有n个结点的树的最大高度h为 n-m+1
