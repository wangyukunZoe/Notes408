# I. 二叉树 🌴 Binary Tree

## 1. 二叉树的定义

二叉树是n (n>=0) 个结点所构成的集合，二叉树可以为空树、也可以为非空树。

对于一颗非空的二叉树 T，它
+ 有且仅有一个称之为 根 `root` 的结点
+ 除去根结点以外的其余部分，分为两个不相交的子树（子集）T1和 T2。其分别构成树的左子树和右子树。T1和 T2自身也是一颗二叉树

二叉树与树都具有递归性质，但相对与普通是树而言，二叉树具有以下几个明显特征：
+  每个结点至多拥有两颗子树（不存在度>2 的结点）
+ 二叉树的子树有明确的左右⇄之分，并且他们的次序不可以调换
+ 二叉树是有序的
## 2. 二叉树的特征和类型

一颗二叉树可以被看作是由一个根节点`root` 和其左右两颗子树T<sub>L</sub> 和T<sub>R</sub>组成。具体可以有 5 种基本形态：
 1) a. 空二叉树
 2) b. 只有根结点的二叉树
 3) c. 只有根结点和左子树的二叉树
 4) e. 只有根结点和右子树的二叉树
 5) d. 具有根结点和左子树和右子树的二叉树![[Pasted image 20260824021018.png]]

## 3. 几种特殊的二叉树
### a. 满二叉树

一棵高度为h且包含2<sup>h</sup> -1个结点的二叉树称为**满二叉树**，即每一层都含有该层所能容纳的最大结点数。满二叉树的所有叶节点均位于最下一层，且除了叶节点以外，其余每个结点的度均为 2。
可对满二叉树按层序进行编号：约定根结点编号为 1，自上而下，自左向右进行依次编号。
在此编号的规则下，对于编号为 i的结点，
+ 若其存在双亲，则双亲编号为（⬇️向下取整i/2）
+ 若存在左孩子，则左孩子的编号为2i
+ 若存在右孩子，则右孩子的编号为 2i+1

*图示为一颗满二叉树*
### b. 完全二叉树

高度为h且包含n个结点的二叉树，当且仅当其每个结点与高度为h的满二叉树中编号为1~n的结点一一对应，则称为完全二叉树
##### 关于完全二叉树特征的小总结：
+ 特征一：在完全二叉树中，叶结点的双亲的左兄弟(若存在)，一定不是叶结点
+ 特征二：高度为h的二叉树最少有2<sup>h-1</sup> 个结点
+ 特征三（小技巧）：若一颗完全二叉树有 n个结点，则该二叉树中的叶节点的个数为n/2个

### c.二叉排序树 binary tree

+ 特征一：其左子树上所有结点的关键字均小于根结点的关键字
+ 特征二：右子树上所有结点的关键字均大于根结点的关键字
+ 并且它的左子树和右子树本身也是一棵二叉排序树
二叉树排序树(binary tree)常用于元素的搜索🔍与排序，具体会在后面的排序和搜索算法里面说

### d. AVL平衡二叉树

这种树是二叉排序树的升级版，可以保证二叉树中任意一个结点的左子树和右子树的高差为 1，且不超过 1。有效的减少元素的重复排序次数。

### e. 正则二叉树

树中每个分支节点均有两个（2）个孩子，即树中仅有度为 0 或度为 2的结点。

## 5. 二叉树的性质
### a. 二叉树中的结点关系（树的层数与结点的关系）

1. 非空二叉树的叶🍃结点数等于度为2的结点树+1，即为`n0 = n2 + 1`
2. 设度为0，1和2的结点数分别为n0,n1和n2, 结点总数为n = n0 + n1 + n2;
3. 考虑到二叉树中存在分支数，除去根节=结点外，其余结点都有一个分支进入，设B为分支总数，由此可以得出：n0 + n1 + n2  = n1 + 2n2 + 1, 从而可以得出n0 = n2 + n1
4. 非空二叉树中的第k层最多有2<sup>k-1</sup> 个结点(k>=0)
5. 高度为h的二叉树🌳至多有2<sup>h</sup>-1个结点（h>=1）
6. 对于完全二叉树按照从上到下、从左到右的顺序依次进行编号1，2，3，… n则具有以下关系：
 A.最后一个分支结点的编号为向下取整n/2 , 如果i<=向下取整n/2,则结点i 为分支结点，后则为叶子结点
 B. 叶子结点只可能出现在最后两层上（相当于在相同高度的满二叉树的最底层、最右侧减少一些连续的叶子结点；当减少两个以上的也结点时，次底层将出现叶🍃结点）
 C.若存在度为1的结点，则最多只可能出现一个，且该结点只有左孩子，没有右孩子。
 D. 按照层序编号后，一旦某一个结点i 为叶结点或仅有左孩子，则所有编号大于i的结点均为叶子结点
 E.如果n为奇数，则每个分支结点都有左有孩子m；如果n为偶数，则所有编号大于i的结点（编号为n/2）只有左孩子没有右孩子，其余分支结点都有左右孩子
 F.当ｉ>1时，结点i的双亲结点的编号为向下取整i/2
 G. z如果结点i拥有左右孩子，则左孩子的编号为2i, 右孩子的编号为2i+1
 H. 结点I所在层次（深度）为向下取整log2i+1
 7. 具有n个结点的完全二叉树的高度为向上取整log<sub>2</sub>(n+1)或向下取整log<sub>2</sub>(n+1)+1

## 6. 二叉树的存储结构

### a. 二叉树的顺序存储

*简单说一下，二叉树实际上很少用顺序存储*
二叉树的顺序存储是使用一组连续的存储单元，按照**自上而下、自左至右**的层序进行排列，依次存储完全二叉树中的结点元素。即将编号为i的结点存储在一维数组下标为`i-1`的位置中。
根据二叉树的性质，完全二叉树和满二叉树非常适合采用顺序存储，它的结点编号能够唯一反映结点之间的逻辑关系，可以最大限度地节省存储空间，又具有数组可以根据下标进行随机访问的特点，快速确定结点在二叉树中的位置及其父子、兄弟👬的关系。
#### 二叉树的顺序存储的相关应用

| 插入方法                                                                                                | 这种做法的缺陷                                                                               |
| --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 对于一颗二叉树来说，如果想通过数组下标来反映逻辑结构，需要插入若干个“空节点”，使其结构与同高度的完全二叉树一致，再将所有结点(包括空结点)按照层序存入数组。这里的空节点可以理解为往数组里面填 0。 | 在最快情况下的插入结点效率很低。只适合顺序存储**完全二叉树**。比如说：一个高度为h 且仅有h 个结点的单支树，却需要占用近2<sup>h</sup>-1 个存储单元。 |

### b. 二叉树的链式存储

*二叉树的链式存储结构的 struct 存储体结构，另外注意这里的链式存储结构在插入的时候不考虑元素相同的结点的情况，考试应该也不会涉及，那个难度比较高，而且也没必要；有点小题大做了。*

因为顺序存储二叉树的效率比较低，二叉树的存储一般情况下使用链式存储。即使用链表结点来存储二叉树中的每个节点。在二叉树的链式存储中，每个结点通常又包括若干数据域和指针域。二叉链表至少包括 3 个域，
+ 左指针域lchild
+ 数据域data
+ 右指针域rchild

*↓下面为一般情况下的二叉树链式存储的数据结构*

```cpp
#include <stdio.h>
#include <stdlib.h>

typedef char BiElemType;
typedef struct BiTNode{
    BiElemType c;   //c是存储 data 数据 c using to store data
    struct BiTNode *lchild;
    struct BiTNode *rchild;
}BiTNode,*BiTree;
```

在实际应用中，还可以根据需要扩展结点结构，例如增加指向父结点的指针域，从而形成三叉链表的存储结构（简单说，可以通过链式存储的方式更方便的扩容）

不同的存储结构会导致二叉树的操作算法的实现不同，有些二叉树也可以通过递归的方式，不依赖队列数据结构进行层次建树。这不过那种方式的空间复杂度会非常高，不建议使用。因此二叉树的建立应该根据实际的应用场景（如二叉树的形态特征及所需要执行的运算类型）选择合适的存储方式。

重要性质：‼️*常出现在选择题中*
在含有`n` 个结点的二叉链表中，共有n+1个空链域
可以利用这些空链域构造一种新的链表结构——线索链表，也就是构建线索二叉树的重要基础。

## 7. 二叉树的遍历

*二叉树的遍历，包括树的遍历的实现，本质上就是函数“递归”的应用*

### a. 前序遍历 （前缀表达式）PreOrder

前序遍历又可以称为先序遍历，具体操作如下：***首先要保证二叉树非空***
+ 先访问根节点
+ 然后再遍历它所附属的左子树，左子树上的结点也要进行先序遍历
+ 然后再遍历它所附属的右子树，右子树上的结点也要进行先序遍历
先序遍历的递归实现如下：

```cpp

// 前序遍历，也是深度优先遍历
void PreOrder(BiTree p)
{
    if(p!=NULL)
    {
        printf("%c", p->c); //打印根节点 print root node
        PreOrder(p->lchild);    // 打印左子树 Print left tree
        PreOrder(p->rchild);    // 打印右子树 print right tree
    }
}
```

#### 前序遍历(先序遍历)的手算方法：

先脑补空节点，从根节点出发，画一条路；如果左边还有没有走的路，优先往左边走，并走到此路的尽头。如果遇到空结点就往回走，如果左右都没有路了，就往上面走。
***一般情况下，前序遍历的二叉树每个结点都会被路过 3 次***

### b.中序遍历 （中缀表达式）InOrder

中序遍历是中缀表达式的重要算法，具体操作如下：***首先要保证二叉树非空***
+ 先访问左子树节点，并对它下面的结点进行中序遍历(中序遍历左子树)
+ 访问二叉树的根
+ 之后访问右子树节点，并对它下面的结点进行中序遍历(中序遍历右子树)
中序遍历的递归实现如下：

```cpp
void InOrder(BiTree p)
{
    if(p!=NULL)
    {
        InOrder(p->lchild);    // 打印左子树 Print left tree
        printf("%c", p->c); //打印根节点 print root node
        InOrder(p->rchild);    // 打印右子树 print right tree
    }
}
```

### c. 后序遍历 (后缀表达式) PostOrder

后序遍历是后缀表达式的重要算法，具体操作如下：***首先要保证二叉树非空***
+ 先访问左子树节点，并对它下面的结点进行后序遍历(后序遍历左子树)
+ 之后访问右子树节点，并对它下面的结点进行中序遍历(后序遍历右子树)
+ 最后访问二叉树的根
中序遍历的递归实现如下：

```cpp
void PostOrder(BiTree p)
{
    if(p!=NULL)
    {
        PostOrder(p->lchild);    // 打印左子树 Print left tree
        PostOrder(p->rchild);    // 打印右子树 print right tree
        printf("%c", p->c); //打印根节点 print root node
    }
}

```

tips: 三种遍历方法的小口诀：前序根左右，中序左根右，后序左右根

关于二叉树的前中后序遍历最常用、最主要的还有用递归方式实现。循环♻️当时也可以实现树的遍历操作，但比较复杂。可以在对空间复杂度有明确要求的情况下使用。

> [!NOTE]
> 需要注意的是：上述三种算法中，递归遍历左右子树的顺序都是固定的，区别只在于访问根结点的时机不同。不论采用哪种遍历方法，**每个结点都只被访问一次，并且仅有唯一一次！**，其时间复杂度为：O(n)。在递归实现中，**系统工作栈的深度等于树的高度**，且在最坏情况下（比如只有单个树，也成为单支树的情况下），空间复杂度为O(n)
> 

### d.层序遍历 lever Order

*要比较留心这个算法，这个算法用到了我们之前用过的 Queue 队列*
层序遍历就是根据树的层数，也可以理解为根据二叉树的深度进行**逐层遍历**。一般顺序为：从上到下、从左到右依次逐层访问二叉树的个各结点，
需要特别注意的是，一般情况下，层序遍历需要一个队列，其基本思路如下：
+ 首先将根结点先入队
+ 并随后不断出队并访问队头(queue_head!)结点.
+ 同时将其存在的左右孩子依次加入队尾，直至队列空🈳。
如果我们说的再直白一点的话：
+ 初始化一个辅助队列
+ 根节点入队
+ 如果队列非空，则队头节点出队；并访问该节点，并将其插入到左、右孩子（如果有的话）
+ 不断循环♻️这个操作。
+ 直到最后的 Queue 辅助队列为空。
下面为层序遍历的基本代码，注意，这里需要用到上一次用到的队列 Queue 数据结构来解决这个问题。
```cpp
// layer traversal 层次遍历 广度优先遍历
void LevelOrder(BiTree T)
{
    LinkQueue Q;
    InitQueue(Q);
    BiTree p; //存储出队的结点
    EnQueue(Q, T);  // 把根入队
    while(!IsEmpty(Q))
    {
        DeQueue(Q, p);
        putchar(p->c);  // 等价于printf("%c", c);
        if(p->lchild)
        {
            EnQueue(Q, p->lchild);  // 左孩子不为空，就入队左孩子
        }
        if(p->rchild)
        {
            EnQueue(Q, p->rchild);  // 有孩子不为空，就入队右孩子
        }

    }
}
```

#### 由遍历序列构造二叉树

简单说，就是利用前面提到的**先序遍历、中序遍历、后续遍历或者是层序遍历**确定一颗二叉树。这个也可以理解为“对二叉树进行遍历的反操作”。
一般情况下，光凭先序和后序、先序与层序中的两两组合是无法判断一棵树的。一般必须要用到**中序序列**。实际上，通过**中序序列**，我们知道了一棵二叉树的***根root***结点在哪里，从而可以通过先序、后序或层序判断出剩余结点到底属于左子树还是右子树。
已知中序序列，并辅以先序、后序或层序中任意一种两两组合，可以唯一地重构（确定）一颗二叉树。下面是以下三种组合的序列。
+ 先序序列和中序序列
在先序序列中的第一个结点一定是二叉树的根结点，根据——***( 根 ) 左 右***  原则。

在中序序列中，根据 ***左（根）右*** 原则，我们可以确定这个树中唯一一个**总的根结点**，从而划分出哪一侧
为左子树，哪一侧为右子树。因为是中序序列，这时候划分出来的左子树部分仍是按照**中序序列**进行排列的，右子树也是一样，这时候就需要对照先序序列，判断出左右子树它们的根在哪里。

再次通过先序序列，我们知道了左右子树的根在哪里，并且进一步由此再次使用使用中序序列，划分出它们各个子树中的左右子树，以此类推。我们可以得到一个由**先序序列和中序序列**唯一确定的二叉树。

tips：一个中序序列可以对应多种二叉树的形态，实际上前序遍历也是一样。

+ 后续序列和中序序列
和刚刚的先序序列和中序序列来确定一颗二叉树的列成差不多，区别在于——由于使用的是后序序列，序列的最后一个结点为各个子树的根。其他的和上面那个方法差不多，这里不做过多的赘述。

+ 层序序列和中序序列
这里需要重点注意一下，在层序序列中，**第一个结点比为二叉树的根结点，由此可以在中序序列中进一步划分出左右子树的中序序列。** 如果存在左子树，则层序序列的第二个结点一定是左子树的根，可以进一步划分出左子树；如果存在右子树，则层序序列的第二个结点一定是右子树的根，可以进一步划分出右子树；通过逐层确定各子树的根结点，并用递归的方法进行划分可以唯一的确定一颗二叉树。

这里需要注意一种特殊的情况——考试中可能会给你二叉树相应的先序遍历和后序遍历，让你去求对应可能存在的中序遍历结点。或者让你取用前面的两种遍历序列求出可能存在的二叉树的形式。

还有一种考试情况就是，会给你一个具体的二叉树的类型，比如完全二叉树，然后再给你一个相关的序列，比如说是一个后序遍历的序列，需要你根据前面两种条件确定出它的先序遍历序列等。
尽管这里不太可能考数据结构的大题或简答题，但是选择题还是很可能在这里涉及并挖坑，需要进一步重视。而且后面对于**非二叉树** 的遍历，即普通树的三种前中后序遍历也非常重要。比较难的话可能会结合图一块考。

## 8. 线索二叉树

线索二叉树可以简单的理解为：利用二叉树的n+1个空链域上的前驱和后继，并将他们父子关系进一步相连，即可得到线索二叉树。

### 为什么提出线索二叉树，相对于一般的遍历有什么优点

+ 可以加快二叉树的遍历速度。
